# Experiments

Each experiment is self-contained: its anonymised participant-level CSV file, R analysis script, and participant-facing materials are in the same folder. Run analysis scripts from the repository root.

| Folder | Included materials |
| --- | --- |
| `experiment-1` | Medication-scenario stimuli for all four conflict-of-interest × result conditions. |
| `experiment-2` | Sewage-treatment-scenario stimuli for all four conflict-of-interest × result conditions. |
| `experiment-3` | Medication-scenario stimuli for all four conflict-of-interest × result conditions. |
| `experiment-4` | Medication-scenario stimuli for all four conflict-of-interest × result conditions. |
| `experiment-5` | Six medication-scenario stimuli, including the external-conflict-of-interest condition. |

## Data variables

The main participant-level files include `ID` (a non-identifying, study-specific participant ID), `COI`, `result`, `AC` (attention-check outcome), `attention_check`, trust ratings, and estimated replicability. Experiment 3 also includes `participant_phd` and `published_empirical`; Experiment 5 also includes `cond`.
