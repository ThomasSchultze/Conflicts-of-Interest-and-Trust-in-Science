# Combined central figure

`Fig1.png` is the publication-ready combined central-results figure. `COI_plots.R` uses the five long-format CSV files in this folder to reproduce it. From the repository root, run:

```r
source("combined-figure/COI_plots.R")
```

The script writes the 600-dpi output to `combined-figure/Fig1.png`, replacing the existing file.
